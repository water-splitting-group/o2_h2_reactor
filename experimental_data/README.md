Contains experimental data from photocatalytic tests and photocatalyst characterization.

`calibration_data`contains original and processed data from calibration of oxygen and hydrogen sensors.

`characterization_data`contains original and processed data from SEM, XRD and BET analyses.

`irradiation_data`contains original data from simultaneous H2 and O2 measurements, containing raw data for each O2 measurement and each H2 measurement per photocatalytic test with summary in Excel file.
